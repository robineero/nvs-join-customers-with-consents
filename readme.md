# Python script to join customers and consents

- Reports used as input need to be UTF-8 encoded CSV files.
- Output of the script will be UTF-8 encoded CSV file and xlsx file named customers_consents_{yymmdd-hhmm}.

### Libraries needed to convert csv to xlsx

Following packages are needed to convert cvs to xlsx: [openpyxl](https://pypi.org/project/openpyxl/), [pandas](https://pypi.org/project/pandas/). Use the following commands to install the packages using [pip](https://pypi.org/project/pip/).

~~~
pip install pandas
pip install openpyxl
~~~
